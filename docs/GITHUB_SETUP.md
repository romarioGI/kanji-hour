# Репозиторий и доступ

Код проекта размещается в приватном репозитории
[romarioGI/kanji-hour](https://github.com/romarioGI/kanji-hour).
Основная ветка — `trunk`. Владелец проекта — romariogi (GitHub: `romarioGI`).

## Участники

Владелец управляет доступом в
[Settings → Collaborators](https://github.com/romarioGI/kanji-hour/settings/access).
Для приглашения выберите **Add people**, найдите точный GitHub-логин участника
и отправьте приглашение. Доступ заработает после его принятия.

Запрошенный участник проекта — [Akane-san](https://github.com/Akane-san).
Этот документ не подтверждает отправку или принятие приглашения: актуальный
статус нужно смотреть в настройках доступа GitHub. Collaborator может работать
с кодом, но доступ не передаёт собственность на репозиторий и не устанавливает
авторство ранее созданных изменений. См. [CONTRIBUTING.md](../CONTRIBUTING.md).

Приватные репозитории и collaborators доступны на
[GitHub Free](https://docs.github.com/en/get-started/learning-about-github/types-of-github-accounts).

## Что хранится отдельно

Ключ подписи, пароль, готовая APK, инструменты SDK и личные изображения
исключены из Git. Не загружайте ранее полученный личный резервный архив
исходников целиком: он содержит ключ подписи. Правила сборки и обновления
указаны в [signing/README.md](../signing/README.md) и [tools/BUILD.md](../tools/BUILD.md).
