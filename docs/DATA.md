# Учебные данные

`app/src/main/assets/kanji.tsv` — ручная подборка 77 базовых японских кандзи,
достаточная для автономного первого выпуска. Это не полный словарь, не официальный
список JLPT и не частотный рейтинг. Русские значения сформулированы кратко для
карточки: они не перечисляют все значения и не заменяют словарь.

## Формат

UTF-8, четыре столбца, разделённые настоящей табуляцией. Первая строка:
`glyph`, `on`, `kun`, `meaning`.

- `glyph`: один иероглиф; повторы запрещены.
- `on`: одно или два стандартных онных чтения катаканой, разделённые `・`.
- `kun`: одно распространённое кунное чтение хираганой. Окуригана включена полностью:
  например, `たべる`, а не только `た`; это полное чтение 食べる.
- `meaning`: краткая русская подсказка из одного–трёх слов.

«Распространённое» здесь означает редакторский выбор для начального обучения,
а не измеренную по корпусу максимальную частотность. У многих знаков есть другие
чтения и значения. Для 千 приведено кунное `ち`, встречающееся в сочетаниях; обычное
чтение числа «тысяча» — онное セン. Для 百 и 万 кунное поле оставлено пустым:
редкие/исторические чтения не включены в этот начальный набор. Это не утверждение
об отсутствии кунных чтений вообще. Конструктор `Kanji` превращает пустое поле
чтения в `—` для одинакового отображения на всех поверхностях. Онное чтение
хираганой вместо отсутствующего кунного не подставляется.

## Сверка

Система записи и несколько неоднозначных мест сверены 7 сентября 2026 года по
漢字ペディア — словарному сервису 日本漢字能力検定協会. Большой внешний словарь
не скачивался; словарные статьи не включены в приложение. Подборка и русские
подсказки составлены для проекта с помощью ChatGPT/Codex, без импорта словаря.
KanjiPedia не объявляет свои материалы открыто лицензированными; ссылка на
него фиксирует справочную сверку и не означает права копировать словарные статьи.
Лицензия проекта не заявляет исключительных прав на сами японские знаки и
языковые факты. Подробнее: [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

- [Правила указания онных и кунных чтений](https://www.kanjipedia.jp/include/popup_onkun.html):
  катакана для онных, хирагана для японских кунных.
- [山](https://www.kanjipedia.jp/kanji/0002633600): サン / やま.
- [日](https://www.kanjipedia.jp/kanji/0005435400): ニチ・ジツ; для карточки выбрано ひ.
- [来](https://www.kanjipedia.jp/kanji/0007020500): ライ; выбрано полное кунное くる.
- [聞](https://www.kanjipedia.jp/kanji/0006190200): ブン・モン; выбрано きく.
- [千](https://www.kanjipedia.jp/kanji/0004026200): セン / ち; см. оговорку выше.
- [万](https://www.kanjipedia.jp/kanji/0006573600): マン・バン, редкое よろず опущено.

## Порядок показа

При первом обращении сохраняется случайный `install_seed` в SharedPreferences
`kanji_hour`. Для этого seed строится одна перестановка всех карточек методом
Фишера–Йетса. Позиция равна положительному остатку от номера UTC-часа:
`floorMod(floorDiv(currentTimeMillis, 3600000), count)`.

Один час всегда соответствует одной карточке на всех поверхностях. В пределах
цикла повторов нет; последний и первый элементы цикла также различаются, если
карточек больше одной. Затем тот же порядок повторяется. Это предсказуемый
псевдослучайный цикл, а не новый независимый случайный выбор каждый час.
Изменение системного времени может сменить карточку; смена часового пояса сама
по себе её не меняет. Планирование перерисовки находится вне этого модуля.

## Проверка алгоритма без Android

Из корня проекта:

```sh
mkdir -p /tmp/kanji-hour-core-tests
javac -d /tmp/kanji-hour-core-tests app/src/main/java/ru/romariogi/kanjihour/HourlySelection.java tests/HourlySelectionTest.java
java -cp /tmp/kanji-hour-core-tests HourlySelectionTest
```

Проверяются стабильность, разные seed, уникальность полного цикла, отсутствие
соседних повторов (включая границы), отрицательные и предельные `long`-часы,
единственная карточка и недопустимые размеры набора.
