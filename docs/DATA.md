# Кандзи

В `app/src/main/assets/kanji.tsv` — 77 базовых кандзи с краткими русскими
значениями. Подборка для начального обучения, без привязки к JLPT.

## Формат

TSV в UTF-8 с заголовком `glyph`, `on`, `kun`, `meaning`.

| Поле | Содержание |
| --- | --- |
| `glyph` | Уникальный иероглиф |
| `on` | Одно–два онных чтения катаканой, разделитель `・` |
| `kun` | Одно кунное чтение хираганой, с окуриганой: `たべる` |
| `meaning` | Русское значение, 1–3 слова |

Кунные чтения выбраны без частотного рейтинга.
У 千 указано `ち`, употребляемое в сочетаниях; обычное
чтение числа — セン. У 百 и 万 редкие кунные чтения опущены. Пустое поле
отображается как `—`.

## Порядок показа

Случайный `install_seed` сохраняется в SharedPreferences `kanji_hour` и задаёт
перестановку Фишера–Йетса. Индекс карточки:

```text
floorMod(floorDiv(currentTimeMillis, 3600000), count)
```

Порядок повторяется каждые 77 часов. Повторов внутри цикла и на его границе нет.
Виджет и обои используют одну карточку на час. Перевод системных часов может
сменить карточку; смена часового пояса — нет.
