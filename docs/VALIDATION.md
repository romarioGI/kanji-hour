# Проверка версии 0.2.0-poco

## Выполнено в среде разработки

- Компиляция XML и Java против официального Android SDK 35.
- Преобразование Java bytecode в DEX с минимальным API 34.
- Сборка устанавливаемого APK, подпись постоянным личным development-ключом.
- Проверка подписи APK и zipalign; совпадение сертификата версии 0.2
  с установленной ранее версией 0.1, versionCode увеличен с 1 до 2.
- Проверка упакованного идентификатора `ru.romariogi.kanjihour`, версии,
  min/target SDK, разрешений и наличия данных в APK.
- Проверка таблицы: 77 уникальных знаков, корректная структура TSV, японская кана
  для чтений, короткие русские значения.
- 27 610 проверок HourlySelection: стабильность по часу и seed, полный цикл без
  повторов, границы цикла, отрицательные и предельные часы, единственная карточка,
  отклонение неправильного размера набора.
- Проверка кода обработки черновика фото, ручной замены обоев, перехода через
  начало часа и отдельных очередей для загрузки фото и broadcast-обновлений.

- 41 проверка WallpaperImportPolicy: выбор отдельного/общего/собственного фона,
  отказ для живых и неизвестных обоев, обнаружение изменения фона во время чтения,
  ограничение памяти декодирования. Это тесты чистой логики, а не Android API.
- Проверка кода возврата из настроек доступа к файлам, отказа, повторного импорта
  и восстановления завершённого результата при пересоздании Activity.

## Не проверено на устройстве

Пользователь подтвердил установку версии 0.1. Версия 0.2 с импортом текущих обоев
ещё не запускалась на физическом POCO или в Android-эмуляторе.
Сборка и подпись подтверждают корректность пакета, но не заменяют приёмочную
проверку интерфейса и поведения HyperOS.

Нужно проверить:

- установку APK, запуск и добавление домашнего виджета;
- читаемость и реальный размер 4 × 1 в текущей сетке лаунчера;
- выбор фото, предпросмотр, применение только к блокировке;
- импорт текущих статических обоев после выдачи доступа к файлам;
- возврат из системных настроек после разрешения и отказа;
- повторный импорт собственных обоев без дублирования кандзи;
- понятное сообщение при живых обоях или отказе HyperOS выдать изображение;
- сохранение почасового обновления после отзыва доступа к общим файлам;
- фактическое положение текста относительно часов, погоды и уведомлений;
- смену после границы часа с закрытым приложением и выключенным экраном;
- сохранение работы после перезагрузки и первого разблокирования;
- отсутствие конфликтов с каруселью обоев и текущей темой Xiaomi;
- отключение смены при замене обоев пользователем;
- поведение без разрешения точного времени и после его предоставления.

Сценарий быстрой проверки описан в основном README. В приложении показываются
время последнего применения, состояние точного разрешения и сообщения об ошибках.
