# Проверки

Версия `0.2.0-poco`, 7 сентября 2026 года.

## Выполнено

- XML и Java собраны с Android SDK 35; DEX — для API 34.
- Подпись APK и zipalign проверены. Сертификат совпадает с версией 0.1;
  `versionCode` повышен до 2.
- В APK проверены пакет `ru.romariogi.kanjihour`, версия, min/target SDK,
  разрешения и данные: 77 уникальных кандзи, структура TSV, кана и русские значения.

| Тест | Проверки | Покрытие |
| --- | ---: | --- |
| `HourlySelectionTest` | 27 610 | Стабильность по часу и seed, цикл без повторов, границы `long`, некорректные размеры набора |
| `WallpaperImportPolicyTest` | 41 | Отдельный, общий и собственный фон; живые и неизвестные обои; смена фона при чтении; лимит декодирования |

Запуск тестов на JVM, из корня проекта:

```bash
mkdir -p build/tests
java -m jdk.compiler/com.sun.tools.javac.Main -d build/tests \
  app/src/main/java/ru/romariogi/kanjihour/{HourlySelection,WallpaperImportPolicy}.java tests/*.java
java -cp build/tests HourlySelectionTest
java -cp build/tests WallpaperImportPolicyTest
```

## Проверить на устройстве

Версия 0.2 не запускалась на физическом POCO или в эмуляторе.

- Установка, запуск, добавление виджета; размер 4 × 1 и читаемость.
- Выбор фото, предпросмотр, применение только к блокировке; положение текста
  относительно часов, погоды и уведомлений.
- Импорт статических обоев; разрешение и отказ в доступе, возврат из настроек.
- Повторный импорт собственных обоев без дублирования кандзи; сообщения об ошибках
  для живых обоев и отказа HyperOS выдать изображение.
- Смена часа с закрытым приложением и выключенным экраном, после перезагрузки
  и первого разблокирования, после отзыва доступа к файлам.
- Работа без разрешения точных событий и после его предоставления.
- Совместимость с темой Xiaomi и каруселью обоев; остановка обновлений при ручной
  замене обоев.

## Живые обои

Матрица добавлена 8 сентября 2026 года по [исследованию](LIVE_WALLPAPERS.md).
Ни один сценарий ниже пока не проверен на устройстве; существующие JVM-тесты
не подтверждают поведение WallpaperManager, лаунчера или HyperOS.

Перед тестом записать версию APK, Android/HyperOS, версию лаунчера, название и
версию поставщика обоев и способ их установки: главный экран, блокировка или оба.
Зафиксировать исходные настройки, чтобы затем восстановить их вручную.

| Сценарий | Проверить | Статус |
| --- | --- | --- |
| Живой главный фон, смена блокировки выключена | Фон виден и анимируется внутри и вне виджета; оба фона не заменяются при смене часа. | Не выполнено |
| Тёмные, светлые и контрастно меняющиеся кадры | Читаемость обоих цветов текста; отсутствие обещания автоматического контраста. | Не выполнено |
| Перелистывание рабочих столов, изменение размера и нажатие на виджет | Нет неподвижной копии фона; карточка открывает приложение; поведение интерактивных обоев записано отдельно. | Не выполнено |
| Живой главный фон + отдельное фото блокировки | Импорт берёт фото блокировки; применение и следующая почасовая смена не заменяют домашний живой фон. | Не выполнено |
| Общий живой фон обоих экранов, только виджет | Анимация и переход разблокировки сохраняются без включения режима блокировки. | Не выполнено |
| Импорт живой блокировки или общего живого фона | Понятный отказ; текущие обои, сохранённый фон, черновик и расписание не меняются. | Не выполнено |
| Явное применение фото поверх живой блокировки | Получается статичный фон; отдельно проверить домашнюю анимацию. «Убрать кандзи» не должно обещать возврат прежних живых обоев. | Не выполнено |
| Установка новых живых обоев на блокировку или оба экрана после включения смены | При доступном изменившемся ID смена останавливается на следующем обновлении; домашний виджет продолжает работать. | Не выполнено |
| Замена только домашнего фона при отдельной статичной блокировке приложения | Смена кандзи на блокировке не останавливается из-за изменения другого экрана. | Не выполнено |
| Super Wallpaper, тема с собственным экраном блокировки, карусель фотографий | Смена часа, переход разблокировки и ручная замена; каждый механизм проверяется отдельно, если доступен на устройстве. | Не выполнено |
| Перезагрузка, выключенный экран, закрытое приложение, отзыв доступа к файлам | После пробуждения кандзи актуален; живой главный фон не заменён. Записать задержки обновления и особенности энергосбережения. | Не выполнено |

### Проверки после доработки защиты

Эти критерии ещё не реализованы полностью и не считаются пройденными:

- При ID `0`, исключении чтения или неизвестном владельце фона автоматическая
  запись и восстановление блокировки приостанавливаются; виджет продолжает работу.
  Сейчас ветка ID `0`/исключения в `wallpaperWasReplaced` разрешает продолжение.
- Отмена подтверждения замены живых обоев оставляет обои, фон приложения и
  расписание без изменений. Отдельного подтверждения живого фона сейчас нет.
- Смена обоев между проверкой и записью не должна молча затираться там, где её
  можно обнаружить повторной проверкой; оставшуюся гонку нужно зафиксировать.

Для недоступных ответов API нужен тест с подменой WallpaperManager или отдельной
обёрткой над ним, а не только ручной тест на телефоне. Итоги добавлять с фактическими
версиями и результатами, не заменяя «Не выполнено» предположениями из исследования.
