# Проверки

Версия `0.2.0-poco`, 7 сентября 2026 года.

## Выполнено

- XML и Java собраны с Android SDK 35; DEX — для API 34.
- Подпись APK и zipalign проверены. Сертификат совпадает с версией 0.1;
  `versionCode` повышен до 2.
- В APK проверены пакет `ru.romariogi.kanjihour`, версия, min/target SDK,
  разрешения и данные: 77 уникальных кандзи, структура TSV, кана и русские значения.

| Тест | Проверки | Покрытие |
| --- | ---: | --- |
| `HourlySelectionTest` | 27 610 | Стабильность по часу и seed, цикл без повторов, границы `long`, некорректные размеры набора |
| `WallpaperImportPolicyTest` | 41 | Отдельный, общий и собственный фон; живые и неизвестные обои; смена фона при чтении; лимит декодирования |

Запуск тестов на JVM, из корня проекта:

```bash
mkdir -p build/tests
java -m jdk.compiler/com.sun.tools.javac.Main -d build/tests \
  app/src/main/java/ru/romariogi/kanjihour/{HourlySelection,WallpaperImportPolicy}.java tests/*.java
java -cp build/tests HourlySelectionTest
java -cp build/tests WallpaperImportPolicyTest
```

## Проверить на устройстве

Версия 0.2 не запускалась на физическом POCO или в эмуляторе.

- Установка, запуск, добавление виджета; размер 4 × 1 и читаемость.
- Выбор фото, предпросмотр, применение только к блокировке; положение текста
  относительно часов, погоды и уведомлений.
- Импорт статических обоев; разрешение и отказ в доступе, возврат из настроек.
- Повторный импорт собственных обоев без дублирования кандзи; сообщения об ошибках
  для живых обоев и отказа HyperOS выдать изображение.
- Смена часа с закрытым приложением и выключенным экраном, после перезагрузки
  и первого разблокирования, после отзыва доступа к файлам.
- Работа без разрешения точных событий и после его предоставления.
- Совместимость с темой Xiaomi и каруселью обоев; остановка обновлений при ручной
  замене обоев.
