# Исправления саморевью PR #6

Базовый коммит ревью: `5f4cd68005e0aa759785a8942289eb544bf36f8f`.
Замечания исправлены тремя последовательными изменениями.

## P2: отмена recovery

Каждый запуск получает собственный RefreshCancellation. onStopJob сопоставляет
задание по jobId (не по ссылке на parcelled JobParameters), отменяет только его
и подавляет запоздавший jobFinished. onDestroy также отменяет незавершённый запуск.
Очередь и независимый почасовой alarm не выключаются.

Отмена проверяется перед выполнением, после подготовки изображения и непосредственно
перед системной записью. Если журнал уже создан, но вызов записи ещё не начат,
журнал снимается без карантина. Кооперативная отмена не прерывает уже начавшийся
вызов WallpaperManager и сохранение его результата: сохранённый ID и чистый источник
должны остаться согласованными. Это не принудительное прерывание системного I/O.

RecoveryJobCancellationTest выполняет реальные Service, Coordinator, RefreshTask
и Controller с тестовыми заменами Android: 36 проверок очереди, повторного запуска,
независимого alarm, отмены при рендере/перед записью/внутри записи и уничтожения service.
Реальное планирование Android и wake locks этим тестом не проверяются.

## P2: обнаружение тестов

Runner компилирует и запускает все обнаруженные *Test.java, включая новые пакеты
и controller-группу, с включёнными Java assertions (-ea). Пустая группа и дубликаты
имён считаются ошибкой; отсутствующий main не пропускается молча.

Пять Python-проверок запускают сам runner в изолированных временных копиях:
новый падающий plain/controller-тест, assert, новые успешные пакеты и пустая группа.
Их подхватывает общий tools/check.py через unittest discovery.

## P3: жизненный цикл предпросмотра

UI-listener подключается в onStart и снимается в onStop. PreviewRequests не запускает
отложенный импорт для невидимого экрана, не публикует устаревший результат после
stop/start и освобождает ненужные Bitmap. Уже выполняющееся чтение может закончиться,
но его результат отбрасывается. При возвращении запрашивается актуальный preview.
Завершение операции в Stopped сбрасывает busy без обновления скрытого UI.

PreviewRequestsTest: 18 проверок реального диспетчера предпросмотра с управляемыми
worker/UI-очередями. Это не тест жизненного цикла Activity на Android.
