# Подпись APK

Локальные файлы: `development.p12` (PKCS#12, RSA 2048, alias `kanji-hour`)
и `development-password.txt`. Храните резервную копию отдельно от репозитория.
Не включайте их в коммиты, релизы и общие архивы.

При первой сборке создаются ключ и случайный пароль с правами `0600`.
Существующая пара используется повторно. Если остался только один файл,
сборка остановится: восстановите второй из резервной копии.

Обновление установленного приложения требует прежнего ключа.
APK из чистого клона получает другую подпись и не установится поверх него.
Срок действия ключа — 10 000 дней с момента создания.

SHA-256 сертификата исходной APK:

```text
9e7aaa58b255e01820667c509475825e247859219fbdd7aa2932ffcc99d76fc3
```
