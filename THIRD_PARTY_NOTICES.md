# Источники и сторонние компоненты

## Код и данные

Код и ресурсы разработаны для проекта с помощью ChatGPT/Codex. Готовые сторонние
исходники и приложения не импортировались. Условия проекта — в [LICENSE](LICENSE).

77 карточек кандзи составлены с помощью ИИ, включая выбор чтений и краткие
русские значения. Это собственная учебная подборка, а не выгрузка словаря.
Чтения выборочно проверены по **KanjiPedia** (公益財団法人 日本漢字能力検定協会).
Страницы сверки и принципы отбора — в [docs/DATA.md](docs/DATA.md).

KanjiPedia не имеет открытой лицензии: см. [о сервисе](https://www.kanjipedia.jp/howto/about.html).
Его статьи, определения и примеры в проект не включены. Лицензия проекта
не распространяется на материалы KanjiPedia и сами языковые факты.

## Оформление

Визуальный ориентир — [видео moji.learn](https://www.instagram.com/reel/Dbbc0_RPbBC/).
Материалы видео в проект не включены.

Иконка создана для проекта. Используются системные шрифты Android.
Обои выбирает пользователь; фотографии в репозитории отсутствуют.

## Сборка

Сторонних библиотек в приложении нет. Инструменты сборки устанавливаются отдельно
и сохраняют собственные условия лицензирования.

| Инструмент | Условия |
| --- | --- |
| Android SDK Platform 35 r2, Build Tools 35.0.1 | [Условия Android SDK](https://developer.android.com/studio/terms) и лицензии отдельных компонентов дистрибутива. |
| JDK 17+ | Лицензия выбранного дистрибутива JDK. |
| Python 3.9+ | [Лицензии Python](https://docs.python.org/3/license.html). |

Версии, ссылки на загрузку и SHA-256 — в [tools/BUILD.md](tools/BUILD.md).
