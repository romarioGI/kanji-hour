# Участие в проекте

Проект ведут **romarioGI** и **Akane-san**. Исходная идея принадлежит Akane-san;
развитие проекта и основные решения — совместная работа.

- Все изменения, включая документацию, CI и версии, — в отдельной ветке от
  актуального `trunk` и через PR. Прямые коммиты/push в `trunk` запрещены правилами проекта.
  Перед слиянием дождитесь успешного `Checks` и устраните замечания ревью.
  Предпочитайте squash — один коммит на PR. В PR опишите изменение и проверки.
- Для сторонних материалов указывайте источник, лицензию и обязательные уведомления
  в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Добавляйте только материалы,
  которые разрешено включать и распространять в составе проекта.
- Для карточек кандзи пишите краткие русские значения и сохраняйте источники
  проверки в [docs/DATA.md](docs/DATA.md).
- Не коммитьте ключи, пароли, APK, резервные копии и личные изображения.
  Инструкции: [сборка](tools/BUILD.md), [подпись APK](signing/README.md).

Минимальная защита на GitHub: для `trunk` — обязательный PR и успешный `Checks`,
запрет перезаписи истории и удаления ветки, без исключений для администраторов;
для `v*` — запрет переноса тегов на другие коммиты и удаления, но не создания.

**На 2026-09-08 защита не включена:** GitHub API требует GitHub Pro для этого
приватного репозитория; у подключённой интеграции также нет административного доступа.
Документация не блокирует прямой push. Настройка администратором в
Settings → Rules → Rulesets — [задача #3](https://github.com/romarioGI/kanji-hour/issues/3).
Тариф и видимость репозитория не менялись.

Отправляя собственный вклад для включения в проект, участник соглашается
распространять его на условиях [MIT License](LICENSE).
