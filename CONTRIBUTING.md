# Участие в проекте

Проект ведут **romarioGI** и **Akane-san**. Исходная идея принадлежит Akane-san;
развитие проекта и основные решения — совместная работа.

- Все изменения в `trunk`, включая документацию, CI, версии и hotfix, — только
  через короткоживущую ветку и PR. Прямые коммиты/push запрещены правилами проекта.
  Перед слиянием дождитесь успешного `Checks` и разберите замечания ревью;
  предпочитайте squash merge. В PR опишите изменение и результат проверки.
- Для сторонних материалов указывайте источник, лицензию и обязательные уведомления
  в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Добавляйте только материалы,
  которые разрешено включать и распространять в составе проекта.
- Для карточек кандзи пишите краткие русские значения и сохраняйте источники
  проверки в [docs/DATA.md](docs/DATA.md).
- Не коммитьте ключи, пароли, APK, резервные копии и личные изображения.
  Инструкции: [сборка](tools/BUILD.md), [подпись APK](signing/README.md).

Минимальная серверная защита: для `trunk` — обязательный PR и успешный `Checks`,
запрет force-push и удаления, без обхода правил; для `v*` — запрет изменения и
удаления тегов, но не создания. Дополнительные обязательные approvals,
CODEOWNERS и merge queue сейчас не вводим.

**Защита пока не включена:** проверка GitHub API 2026-09-08 показала, что для
текущего приватного репозитория функция требует GitHub Pro; у подключённой
интеграции также нет административного доступа. Документация не блокирует push.
Активация администратором в Settings → Rules → Rulesets отслеживается в
[issue #3](https://github.com/romarioGI/kanji-hour/issues/3). Тариф и видимость не менялись.

распространять его на условиях [MIT License](LICENSE).
