# Совместная работа

Проект ведёт **romariogi** (GitHub: `romarioGI`). Доступ к приватному
репозиторию предоставляет его владелец. Условия работы — в [LICENSE](LICENSE).

- Изменения делайте в отдельной ветке; опишите цель и результат проверки в pull request.
- Добавляя сторонний код, данные или изображения, укажите точный источник,
  применимую лицензию и необходимые уведомления в `THIRD_PARTY_NOTICES.md`.
  Если право включить материал не установлено, не добавляйте его.
- Для кандзи сохраняйте краткие собственные русские подсказки и источники проверки
  в `docs/DATA.md`. Не импортируйте внешние словари под лицензией этого проекта.
- Не коммитьте закрытые ключи, пароли, APK, архивы резервных копий, личные фотографии
  и скриншоты. Для сборки см. `tools/BUILD.md`, для подписи — `signing/README.md`.
- Отмечайте помощь AI и заимствования достоверно. Сохраняйте фактическое авторство
  изменений; приглашение в collaborators само по себе не делает человека автором
  ранее созданного кода. `Co-authored-by` уместен при реальном совместном вкладе.

Отправляя собственный вклад для включения в проект, участник предлагает его
на условиях раздела Contributions в LICENSE. Это не передаёт права на чужие
материалы и не делает владельца репозитория автором всех изменений.
