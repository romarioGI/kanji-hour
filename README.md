# Кандзи · час

Кандзи с чтениями и русским переводом, новый каждый час.
Для POCO X5 Pro 5G: Android 14, HyperOS 2.0.11.0.UMSRUXM, экран 1080 × 2400.

- 77 карточек: онные чтения, одно кунное, значение в 1–3 слова.
- Прозрачный виджет 4 × 1 на главном экране.
- Карточка на экране блокировки как часть обоев.
- Общий для обоих экранов порядок без повторов в цикле из 77 часов.
- Работает офлайн.

## Установка

Получите `kanji-hour-poco.apk` у владельца проекта или [соберите APK](tools/BUILD.md).
Обновления устанавливаются поверх предыдущей версии с тем же ключом подписи.

1. Установите APK и откройте **Кандзи · час**.
2. Нажмите **Добавить виджет**. Если окно не появилось, добавьте его через меню виджетов лаунчера.
3. Для блокировки нажмите **Выбрать исходное фото** или **Взять текущие обои блокировки**.
4. Настройте размер и положение, затем нажмите **Применить фон и включить смену**.
5. Через **Настроить точное время** разрешите **Будильники и напоминания**.
6. В настройках HyperOS включите фоновый автозапуск и режим батареи **Без ограничений**.

## Обои блокировки

Импорт текущих обоев требует разрешения **Доступ ко всем файлам**.
После импорта его можно отозвать кнопкой **Отключить доступ к файлам**:
приложение продолжит работать с сохранённой копией. Выбор фото вручную этого разрешения не требует.

Импорт загружает фон в предпросмотр; кнопка применения меняет только обои блокировки.
**Убрать кандзи с блокировки** останавливает смену и восстанавливает выбранный статичный
фон без текста, а не прежние живые обои.
При обнаружении замены обоев вручную автоматическая смена также останавливается.

## Живые обои

На главном экране виджет прозрачен: импортировать фон для него не нужно.
На блокировке приложение создаёт статичное изображение и заменяет им живые обои.
Чтобы сохранить анимацию на обоих экранах, используйте только домашний виджет,
оставив смену на блокировке выключенной.
Совместимость с целевой прошивкой ещё не проверена — см. [исследование](docs/LIVE_WALLPAPERS.md).

## Ограничения

- AOD не поддерживается. Карточка на блокировке не нажимается.
- Фото кадрируется по центру до 1080 × 2400; положение самого фото не настраивается.
- Без разрешения на точное время обновления могут задерживаться.
  Принудительная остановка приложения прекращает их до следующего запуска.
- Импорт обоев в версии 0.2 и работа в фоне ещё требуют [проверки на устройстве](docs/VALIDATION.md).
