# Кандзи · час

Кандзи с чтениями и русским переводом, новый каждый час.
Для POCO X5 Pro 5G: Android 14, HyperOS 2.0.11.0.UMSRUXM, экран 1080 × 2400.

Прозрачный виджет 4 × 1 и кандзи на текущих статичных обоях блокировки.
77 карточек, общий порядок без повторов внутри цикла, работа офлайн.

## Установка

Получите APK у владельца проекта или [соберите его](tools/BUILD.md).
Обновления устанавливаются с тем же ключом подписи.

1. Установите приложение и нажмите **Добавить виджет** для главного экрана.
2. Для блокировки откройте **Доступ к текущим обоям**, разрешите чтение,
   настройте положение и размер и нажмите **Применить к текущим обоям**.
3. Через **Настроить точное время** разрешите **Будильники и напоминания**.
   В HyperOS включите фоновый автозапуск и режим батареи **Без ограничений**.

## Текущие обои

Выбора фото и встроенных фонов нет. Обои меняются обычным способом в Android;
при ближайшем обновлении приложение подхватывает новый статичный фон блокировки,
даже если час ещё не сменился. Чистая копия хранится внутри приложения:
старый кандзи не накладывается поверх нового. Запись выполняется только для блокировки.

Для чтения новых обоев на Android 14 нужен **Доступ ко всем файлам**.
Чтобы новые фоны подхватывались автоматически, доступ должен оставаться включённым.
Приложение не сканирует общие каталоги. После отзыва доступа проверенный собственный
фон может обновляться из чистой копии, но новые обои не будут прочитаны.

**Отключить и убрать кандзи** останавливает автосмену и убирает текст только
с собственных обоев. Если фон уже заменили, приложение не возвращает старую картинку.
Живые, неизвестные и недоступные обои остаются нетронутыми; домашний виджет независим.

## Ограничения

Обновление не требует постоянно открытого приложения. AlarmManager запускает
почасовую смену, отдельный JobScheduler восстанавливает её после сбоев.
Задержки Doze и HyperOS возможны; мгновенная реакция на ручную смену не гарантируется.
После принудительной остановки нужно снова открыть приложение.

Фон кадрируется по центру до 1080 × 2400. Кандзи — часть статичного изображения,
не отдельный слой; AOD и нажатия на него не поддерживаются. Общий статичный фон
считывается только при отсутствии отдельной блокировки; после применения блокировка
становится отдельной. Исходная связь экранов при удалении текста не восстанавливается.
Совпадение кадрирования с темой HyperOS и работа в фоне требуют проверки на устройстве.

## Разработка

Java, Android SDK, без сторонних библиотек. Пакет `ru.romariogi.kanjihour`.
Минимальный и целевой API — 34, compile SDK — 35. Версия исходников — `0.3.1-poco`.

```sh
python3 tools/test.py
python3 tools/check_android.py --sdk /path/to/android-sdk
```

Первая команда запускает JVM-проверки, вторая компилирует ресурсы, Java и DEX
без создания ключей и релизного APK. Это не тестирование на Android-устройстве.
