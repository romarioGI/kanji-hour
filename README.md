# Кандзи · час — для romariogi

Пробная версия 0.2.0 для **POCO X5 Pro 5G, Android 14, HyperOS
2.0.11.0.UMSRUXM**. Макет рассчитан на экран 1080 × 2400 и присланное расположение
часов, даты и погоды. Личный проект для этого телефона.

## Что входит

- Прозрачный домашний виджет 4 × 1: крупный кандзи слева, онные и одно
  распространённое кунное чтение справа, русское значение в одну–три словоформы.
- 77 базовых знаков офлайн. Нет рекламы, аналитики, аккаунта и разрешения INTERNET.
- Общая карточка часа для главного экрана и блокировки. Псевдослучайный порядок
  без повторов в одном цикле из 77 часов; затем цикл повторяется.
- Экран блокировки: кандзи вписывается в выбранный фон, а приложение обновляет
  именно **обои блокировки**. Это не нативный виджет внутри штатной блокировки.
- Автоматический импорт текущих обоев блокировки в предпросмотр.
- Выбор исходной фотографии, предварительный просмотр, сдвиг по высоте и размер.
  Начальный центр блока — 38,2% высоты, ниже погоды на присланном скриншоте.
- Восстановление расписания после перезагрузки и обновления приложения.

## Установка

Готовую APK можно получить у владельца проекта или собрать по
[инструкции](tools/BUILD.md). Для обновления установленной личной версии нужна
APK с исходной подписью; новая подпись из чистого клона для этого не подходит.

1. Откройте `kanji-hour-poco.apk` на телефоне и установите поверх прежней версии
   (удалять приложение не нужно). Если Android спросит,
   разрешите установку из приложения, которым вы открыли APK.
2. Запустите **Кандзи · час**.
3. Нажмите **Добавить виджет**. Если лаунчер не покажет окно добавления, зажмите
   свободное место на главном экране → **Виджеты** → **Кандзи · час**.
   Разместите блок между часами и первым рядом значков. Для светлого фона уже
   выбран тёмный текст.
4. Для блокировки нажмите **Взять текущие обои блокировки** → **Открыть настройки**.
   Разрешите **Доступ ко всем файлам** для «Кандзи · час» и вернитесь назад:
   фон автоматически загрузится в предпросмотр. Если система открыла список
   приложений, сначала выберите «Кандзи · час». Android требует это широкое
   разрешение для чтения текущих обоев; код использует его только для импорта.
   Альтернатива — **Выбрать исходное фото** (без часов и значков) или синий фон.
5. Проверьте предпросмотр и нажмите **Применить фон и включить смену**.
   Эта кнопка заменяет обои экрана блокировки. Домашний фон приложение не меняет.
6. Нажмите **Настроить точное время**, разрешите **Будильники и напоминания**.
   Без разрешения смена работает с возможной задержкой Android.
7. В настройках приложения HyperOS включите фоновый автозапуск и режим батареи
   **Без ограничений**. Пункты могут называться немного иначе на этой сборке.

## Импорт текущих обоев

- После загрузки нажмите **Применить фон и включить смену** — сам импорт ничего
  не устанавливает и не включает почасовую смену на блокировке.
- Доступ к общим файлам нужен только для первоначального чтения. Кнопка
  **Отключить доступ к файлам** открывает системный переключатель; после отключения
  приложение продолжает обновлять сохранённый фон из своего приватного каталога.
- Разрешение запрашивается только после нажатия на импорт. Отклонение запроса
  не мешает домашнему виджету и выбору фотографии вручную.
- Если на блокировке уже наш кандзи, приложение берёт сохранённый чистый фон,
  чтобы не получить два наложенных знака. В этом случае доступ к файлам не нужен.
- Если отдельные обои блокировки не установлены, импортируется общий статический
  фон. Живые обои и анимации не импортируются: приложение покажет причину.
- Импортируется системная копия обоев, а не гарантированно исходный файл фотографии
  в полном разрешении. Кадрирование в HyperOS нужно проверить в предпросмотре.

## Первая проверка на POCO

Версия 0.1 уже установлена пользователем. Обновление 0.2 собрано и подписано,
но новый импорт на физическом POCO ещё не проверен.
Совместимость программной смены обоев и стабильность фонового режима нужно
подтвердить на устройстве.

1. Заблокируйте и включите экран: виден ли знак под погодой, не перекрывает ли
   он часы и дату? Если нужно, подвиньте блок в приложении и снова примените.
2. Проверьте, что фон главного экрана остался прежним и оба экрана показывают
   одинаковый знак. Если Xiaomi кадрирует обои иначе, пришлите скриншот результата.
3. Нажмите **Проверить обновление сейчас**: внутри часа знак остаётся тем же,
   проверяется перерисовка и применение. Ошибки показываются в приложении.
4. Пересеките границу часа с закрытым приложением, затем проверьте оба экрана.
   Отдельно проверьте после перезагрузки и первого разблокирования.
5. Если карусель обоев или тема Xiaomi заменяет фон, отключите соответствующую
   автоматическую смену и снова примените фон приложения.

## Ограничения версии

- **AOD не реализован.** Целевой сценарий — включённый экран блокировки.
- Кандзи на блокировке не нажимается: он является частью изображения.
- Исходное фото кадрируется по центру до 1080 × 2400. Ручное кадрирование и
  перемещение самого фото пока отсутствуют.
- Фото и положение сначала меняются только в предпросмотре. Применение включается
  отдельной кнопкой. Кнопка **Убрать кандзи с блокировки** останавливает смену
  и оставляет выбранный фон без текста.
- Если приложение обнаруживает, что обои заменены вручную, оно останавливает
  автоматическую смену. Проверка использует ID обоев Android; поведение Xiaomi
  также нужно подтвердить на устройстве.
- Точное разрешение помогает соблюсти начало часа, но не доказывает надёжность
  конкретной HyperOS. Принудительная остановка приложения в настройках может
  отменить обновления до следующего запуска.
- Кунное чтение выбрано редакторски для начального обучения, а не по доказанному
  частотному рейтингу. Все чтения каждого знака в маленькой карточке не помещаются.
  Подробнее: [данные и источники](docs/DATA.md).

приложения нужен именно этот ключ. Новый клон без него создаст другую подпись.
